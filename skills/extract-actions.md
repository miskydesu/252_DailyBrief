# Skill: アクション項目の抽出

議事録本文から「誰が・何を・いつまでに」のアクション項目を抽出する。

## 入力

- meeting.title
- meeting.notes（議事録本文）
- meeting.attendees
- meeting.date

## 抽出ルール

### アクションとみなすパターン

以下の表現が出てくる箇所を起点に、アクション項目を抽出：

- 「〜する」「〜します」「〜しておく」「〜してください」
- 「TODO:」「ToDo:」「Action:」「アクション:」「宿題」
- 「〇〇さんが〜」「〇〇さんに〜」（割り当て表現）
- 「次回までに」「今週中に」「来週」「月末まで」（期限表現）
- 「決定事項」「合意」の直後に出てくる行動コミット

### 除外パターン

以下はアクションと**みなさない**：

- 一般論・方針の記述（「重要だね」「必要だと思う」止まり）
- 過去形のみの記述（「〜しました」「〜していた」）
- 議論の引用部分

## 担当者の解決

「〇〇さんが」と書かれていたら、参加者リストから氏名マッチで担当者を特定する。
苗字だけの場合は参加者リストの中で一意なら確定、複数いる場合は「〇〇（要確認）」とする。

主語省略の場合：
- 議事録の文脈で直前に話していた人のアクションと推定
- 推定が難しい場合は **「未割当」** とする

## 期限の解決

- 「来週」→ ミーティング日付の翌週金曜日
- 「今週中」→ ミーティング日付のその週金曜日
- 「月末まで」→ ミーティング月の末日
- 「次回まで」→ 同じ会議体の次回開催日（カレンダーから検索、なければ「次回MTG」）
- 明示的な日付（「5/10」「来月15日」）→ そのまま日付に変換
- 期限不明 → **「未定」**

## 出力フォーマット

```yaml
actions:
  - assignee: 松林
    task: XXX案を整理
    deadline: "2026-05-08"
    confidence: high
    source_quote: "松林さんがXXX案を5/8までに整理"
  - assignee: 未割当
    task: YYY を中川に展開
    deadline: "2026-05-10"
    confidence: medium
    source_quote: "YYYは来週中に中川さんに渡す方向で"
```

## 重複排除

同じ議事録内で同じアクションが複数回言及される場合は1件にまとめる。
判定基準：assignee と task の意味的類似度が高ければ重複とみなす。

## 出力時の表示優先度

1. 担当者が user.name 本人のもの → 最上位
2. 期限が今週中のもの → 上位
3. その他

CLAUDE.md の Slack Canvas 出力時には、上記優先度で並べる。
